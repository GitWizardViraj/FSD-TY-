HTML TAGS WITH INFORMATION

Tag Details Syntax Example
html Root tag of HTML document <html>...</html> <html>Content</html>
head Contains page information <head>...</head> <head><title>My Page</title></head>
title Sets browser tab title <title>...</title> <title>Home</title>
body Contains visible content <body>...</body> <body>Hello</body>
h1 Main heading <h1>...</h1> <h1>Welcome</h1>
p Paragraph text <p>...</p> <p>This is text</p>
a Creates hyperlink <a href="">text</a> <a href="https://google.com">Google</a>
img Displays image <img src="" alt=""> <img src="pic.jpg" alt="img">
br Line break <br> Hello<br>World
table Creates table <table>...</table> <table><tr><td>A</td></tr></table>
